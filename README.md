# Cursor for Product Managers

**An interactive course teaching PMs how to use Cursor AI for daily product work**

---

## 🎯 What is This?

This is an interactive, hands-on course that teaches Product Managers how to use **Cursor** - an AI-powered IDE - for PM work like writing PRDs, analyzing user research, processing data, creating roadmaps, and more.

The full course lives at **[cursorforpms.com](https://cursorforpms.com)** - 3 modules, 16 lessons, taught entirely inside Cursor itself.

---

## 🚀 Quick Start

### Prerequisites

1. **Cursor installed** - Download from [cursor.com](https://cursor.com)
2. **Cursor account** (free or paid)

### How to Start

This course uses Cursor's Agents view. Open Cursor, start a new project, open the Agents view (`Cmd+I` / `Ctrl+I`), and paste:

```text
Fetch fullstackpm.com/cli and help me start Cursor for Product Managers
```

The AI sets up the course materials in your project and walks you through starting Module 1.1.

**Prefer to clone?** Clone this repo, open the `course-materials` folder in Cursor, open the Agents view, and type `/start-1-1`.

Full setup guide: [cursorforpms.com/getting-started/opening-course-folder](https://cursorforpms.com/getting-started/opening-course-folder)

## 🎓 How This Course Works

### Interactive Teaching

Unlike traditional courses where you read and then try things:

1. **Type a slash command** (e.g., `/start-1-1`)
2. **The AI becomes your instructor** - guides you step-by-step
3. **You practice immediately** - hands-on exercises
4. **Get feedback in real-time** - the AI checks your understanding
5. **Progress through modules** - each builds on the last

### Teaching Mechanism

This course uses Cursor's features to create an interactive learning experience:

- **Slash commands** (`.cursor/commands/`) trigger each module
- **Teaching scripts** (`lesson-modules/`) guide the AI on how to teach
- **Project rules** (`.cursor/rules/`) establish course context and instructor personality
- **Pre-created files** (`company-context/`) provide realistic PM documents
